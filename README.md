## Предметна область

Інтернет-магазин - каталог товарів та замовлення.

## Сутності: Товар (Product) та Клієнт / Замовлення (Order)

| Характеристика | Тип | Опис |
| :--- | :--- | :--- |
| `customerName` | String | Ім'я клієнта/покупця |
| `productTitle` | String | Назва замовленого товару |
| `category` | String | Категорія товару |
| `price` | double | Ціна за одиницю товару (в грн) |
| `quantity` | int | Кількість одиниць товару (шт.) |
| `rating` | double | Користувацький рейтинг товару (від 1.0 до 5.0) |
| `isExpress` | boolean | Потреба в експрес-доставці (`true` — так, `false` — ні) |

## Обчислювальні операції

- **Вартість товарів (`subtotal`)** — добуток ціни та кількості: `price * quantity`.
- **Розрахунок знижки** — прогресивна шкала:
  - від 5000 грн — `10%`;
  - від 2500 грн — `5%`;
  - менше 2500 грн — `0%`.
- **Розрахунок вартості доставки (`deliveryCost`)** — базова доставка безкоштовна при вартості замовлення після знижки від 1500 грн, інакше — 150 грн; при виборі експрес-доставки (`isExpress = true`) додається фіксована доплата `100 грн`.
- **Оцінка рейтингу** — класифікація товару на категорії за пороговими значеннями:
  - від 4.5 — "Високий рейтинг (Хіт продажу!)";
  - від 3.0 — "Середній рейтинг (Добрий вибір)";
  - менше 3.0 — "Низький рейтинг".
- **Фінальна сума до сплати (`finalTotal`)** — підсумок вартості товарів, знижки та доставки: `subtotal - discountAmount + deliveryCost`.

## Форматування виводу

Грошові суми (ціна, вартість, знижка, доставка, підсумок) та рейтинг товару форматуються через `System.out.printf` з двома знаками після коми (`%.2f`) та кросплатформним закінченням рядка `%n`.

## Запуск

```bash
chcp 65001 > nul
javac -encoding UTF-8 Main.java
java -Dfile.encoding=UTF-8 Main
```

АБО

Запустити файл `run.bat`:
```bash
@echo off
chcp 65001 > nul
javac -encoding UTF-8 Main.java
java -Dfile.encoding=UTF-8 Main
pause
```
