# Лабораторна робота №4: Реалізація програмних інтерфейсів мовою Java

## Предметна область: Інтернет-магазин

Робота є логічним продовженням ЛР №1–3. У ній поведінка розрахунку знижок та доставки замовлення винесена в інтерфейси з кількома реалізаціями, застосовано default-методи, шаблон «абстрактний клас + інтерфейс», множинну реалізацію інтерфейсів та патерн Strategy.

---

## Сутності проєкту

- **Customer** — покупець із валідацією номера телефону.
- **Product** — товар на складі. Реалізує два інтерфейси: `Comparable<Product>` (поведінка сортування за ціною) та `Purchasable` (бізнес-поведінка покупки).
- **Purchasable** — інтерфейс бізнес-поведінки товару (`buy`, `getQuantity`, default-метод `isInStock`).
- **DiscountStrategy** (пакет `discount`) — інтерфейс стратегії знижки (`calculateDiscount`, `getName`, default-метод `describe`).
  - `NoDiscount` — знижка 0 грн (перевизначає `describe`).
  - `ThresholdDiscount` — програма лояльності (5% від 2500 грн, 10% від 5000 грн).
  - `PromoCodeDiscount` — знижка 15% за промокодом SALE15.
- **Delivery** (пакет `delivery`) — інтерфейс розрахунку вартості доставки (`calculateCost`, `getName`).
  - `AbstractDelivery` — абстрактний клас зі спільною логікою кур'єрських доставок (поріг безкоштовної доставки від 1500 грн).
  - `StandardDelivery` — стандартна доставка кур'єром (150 грн).
  - `ExpressDelivery` — експрес-доставка кур'єром (150 грн + 100 грн доплати).
  - `PickupDelivery` — самовивіз (0 грн, реалізує інтерфейс `Delivery` напряму).
- **Order** — замовлення (контекст патерна Strategy). Делегує розрахунок вартості знижці та доставці, підтримує зміну стратегії знижки під час виконання програми (`setDiscountStrategy`).
- **Main** — консольне меню для взаємодії з користувачем.

---

## Реалізовані рівні складності

### Рівень 1. Базовий
- Визначено варіативну поведінку предметної області — розрахунок знижки.
- Створено інтерфейс `DiscountStrategy`.
- Реалізовано 3 класи: `NoDiscount`, `ThresholdDiscount`, `PromoCodeDiscount`.
- Продемонстровано поліморфізм: пункт меню 7 обходить масив `DiscountStrategy[]` у циклі та викликає метод для кожного об'єкта.

### Рівень 2. Середній
- Додано default-метод `describe` в інтерфейс `DiscountStrategy` (успадковується класами `ThresholdDiscount` та `PromoCodeDiscount`, перевизначається у `NoDiscount`).
- Реалізовано шаблон «абстрактний клас + інтерфейс»: `AbstractDelivery implements Delivery` містить спільний поріг безкоштовної доставки для `StandardDelivery` та `ExpressDelivery`. Клас `PickupDelivery` реалізує "чистий" інтерфейс `Delivery` напряму.
- Клас `Product` реалізує два інтерфейси одночасно: `Comparable<Product>` (поведінка сортування) та `Purchasable` (поведінка покупки).

### Рівень 3. Високий
- Застосовано патерн Strategy: контекстний клас `Order` приймає `DiscountStrategy` та `Delivery` в конструкторі та делегує їм розрахунки.
- Реалізовано зміну стратегії під час виконання програми: у пункті меню 6 при введенні промокоду `SALE15` викликається `order.setDiscountStrategy(new PromoCodeDiscount())` для вже створеного замовлення.
