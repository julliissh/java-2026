# Лабораторна робота №2: Опрацювання масивів із застосуванням циклів

## Предметна область: Інтернет-магазин (каталог товарів та кошик покупця)

Дана лабораторна робота є логічним продовженням ЛР №1 і реалізує роботу з масивами об'єктів у контексті електронної комерції: створення кошика клієнта, збереження товарів у масиві, фільтрація, сортування та лінійний пошук за зразком.

---

##  Опис сутностей (класів)

### 1. Клас `Customer` (Клієнт)
Представляє покупця інтернет-магазину.
| Поле | Модифікатор | Тип | Опис |
| :--- | :--- | :--- | :--- |
| `name` | `private` | `String` | Ім'я клієнта |
| `phone` | `private` | `String` | Номер телефону для зв'язку |

**Методи:**
- `Customer(String name, String phone)` — конструктор;
- `getName()` — отримання імені клієнта;
- `getPhone()` — отримання номера телефону;
- `toString()` — текстове представлення клієнта.

### 2. Клас `Product` (Товар)
Представляє товар у каталозі / кошику.
| Поле | Модифікатор | Тип | Опис |
| :--- | :--- | :--- | :--- |
| `name` | `private` | `String` | Назва товару |
| `category` | `private` | `String` | Категорія товару |
| `price` | `private` | `double` | Ціна за одиницю товару (в грн) |
| `quantity` | `private` | `int` | Кількість одиниць (шт.) |

**Методи:**
- `Product(String name, String category, double price, int quantity)` — конструктор;
- `getName()`, `getCategory()`, `getPrice()`, `getQuantity()` — геттери для читання полів;
- `toString()` — форматований вивід товару;
- `equals(Object obj)` — перевірка повної рівності двох об'єктів за всіма полями через геттери.

---

##  Реалізований функціонал (усі 3 рівні)

### Рівень 1. Базовий
- Створено клас `Product` із 4 полями різних типів, конструктором та методом `toString()`.
- Створено клас `Customer` для фіксації покупця.
- Заповнення масиву об'єктів `Product[]` фіксованого розміру з клавіатури за допомогою `Scanner` у циклі `for`.
- Виведення всіх елементів масиву на екран за допомогою циклу `for-each` із зазначенням клієнта через `customer.getName()` та `customer.getPhone()`.
- **Підсумок:** підрахунок кількості товарів за бюджетом (дешевші за поріг) та розрахунок загальної кількості штук у замовленні (`getQuantity()`).

### Рівень 2. Середній
- Ручна реалізація алгоритму **сортування бульбашкою (Bubble Sort)** за зростанням ціни (`price`) без використання готових бібліотек (`Arrays.sort()` або `Comparable`).
- Наочне виведення масиву **до** та **після** сортування.

### Рівень 3. Високий
- Перевизначено метод `equals(Object obj)` у класі `Product` із повною перевіркою адреси посилання (`==`), `null`, `getClass()` та порівнянням усіх полів через геттери без сторонніх бібліотек на зразок `Double.compare()` чи `Objects.equals()`.
- Реалізовано метод **лінійного пошуку** об'єкта в масиві за повним збігом об'єкта-зразка (`equals()`).
- Виведення назви знайденого товару (`getName()`), його індексу в масиві та повних характеристик.

##  Інструкція запуску

### Вимоги:
- Встановлений  **Java 25 LTS**.
- Підтримка кодування UTF-8 у терміналі.

### Варіант 1: Швидкий запуск через `run.bat` (Windows)
Просто двічі клацніть файл `run.bat` у папці проєкту або виконайте в терміналі:
```cmd
run.bat
```

### Варіант 2: Запуск через консоль вручну
```powershell
chcp 65001 > nul
javac -encoding UTF-8 Customer.java Product.java Main.java
java -Dfile.encoding=UTF-8 Main
```
