# Лабораторна робота №3: Опрацювання виняткових ситуацій (Exception)

## Предметна область: Інтернет-магазин (каталог товарів та замовлення покупця)

Робота є логічним продовженням ЛР №1 та ЛР №2. У ній реалізовано захист програми від некоректних даних і помилок користувача за допомогою механізму обробки виключень Java (try, catch, finally, throw, throws), побудовано власну ієрархію перевірених (checked) винятків у пакеті exception, додано бізнес-логіку оформлення покупки з розрахунком знижки й доставки (з ЛР №1) з використанням статичних констант, а також реалізовано зручне консольне меню.

---

## Ієрархія виключень (пакет exception)

Усі власні винятки логічно об'єднані навколо базового доменного класу магазину ShopException:

```text
java.lang.Exception (Checked)
    └── ShopException (базовий клас помилок інтернет-магазину)
            ├── InvalidPriceException (ціна <= 0, зберігає invalidPrice)
            ├── InvalidQuantityException (кількість <= 0, зберігає invalidQuantity)
            ├── InvalidPhoneException (некоректний формат телефону клієнта, зберігає invalidPhone)
            └── InsufficientStockException (недостатньо на складі, зберігає requestedQuantity та availableQuantity)
```

1. **ShopException** — базовий unchecked-клас для доменних помилок інтернет-магазину (extends RuntimeException).
2. **InvalidPriceException** — сигналізує про неприпустиму ціну товару (price <= 0), зберігає invalidPrice.
3. **InvalidQuantityException** — сигналізує про неприпустиму кількість товару (quantity <= 0), зберігає invalidQuantity.
4. **InvalidPhoneException** — сигналізує про некоректний номер телефону покупця (перевірка регулярним виразом формату України), зберігає invalidPhone.
5. **InsufficientStockException** — сигналізує про недостатню кількість товару на складі при покупці, зберігає requestedQuantity та availableQuantity.

## Реалізовані рівні складності (1–3)

### Рівень 1. Базовий
- **Безпечне введення чисел:** перехоплення InputMismatchException при спробі ввести текст замість числа в консолі або меню через Scanner.
- **Обробка меж діапазонів:** використання IndexOutOfBoundsException при виборі неіснуючого номера товару для купівлі.
- **Перевірка некоректних значень:** використання IllegalArgumentException для валідації бюджетного ліміту та вибору варіанта доставки.
- **Блок finally:** гарантовано закриває Scanner при завершенні програми для звільнення системних ресурсів.

### Рівень 2. Середній
- **Власні unchecked-виключення в окремому пакеті exception:** ShopException, InvalidPriceException, InvalidQuantityException, InvalidPhoneException, InsufficientStockException (наслідують RuntimeException) із викликом super(message) та полями збереження помилкових значень.
- **Конструктори та методи сутностей із throw new:**
  - Customer(name, phone) — валідує номер телефону регулярним виразом формату України.
  - Product(name, category, price, quantity) — валідує параметри створення товару.
  - Product.buy(amount) — перевіряє кількість одиниць для списання зі складу (генерує InsufficientStockException або InvalidQuantityException).
- **Відновлення роботи:** програма не переривається аварійно при помилках введення чи винятках, а виводить зрозуміле повідомлення та повертається до меню або повторного вводу.

### Рівень 3. Високий
- **Кілька блоків catch (пункт 9):** 
  - У методі `addProduct(...)` блок try містить послідовні catch для `InputMismatchException`, `InvalidPriceException` та `ShopException` (спеціалізований виняток розташований перед базовим).
  - У методі `checkout(...)` конкретні `InsufficientStockException` та `InvalidQuantityException` розташовані перед базовим `ShopException`.
- **Механізм Re-throw (пункт 10):** метод `createProduct(...)` перехоплює помилку ціни (`InvalidPriceException`), виконує аудит/логування (`[ЛОГ/АУДИТ]: Спроба створення товару з неприпустимою ціною...`), після чого повторно збуджує виняток (`throw e;`) для обробки на вищому рівні в `addProduct(...)`.
- **Перехоплення базовим класом обох підтипів (пункт 11):** у методі `searchInCatalog(...)` при створенні товару-зразка один блок `catch (ShopException e)` поліморфно перехоплює обидва дочірні підкласи (`InvalidPriceException` та `InvalidQuantityException`) без дублювання блоків catch.

## Організація статичних констант та усунення «магічних чисел»

Основні налаштування та значення бізнес-логіки винесені у статичні константи для уникнення «магічних чисел» і спрощення зміни параметрів програми:

1. **Клас Customer:**
   - `PHONE_REGEX` — регулярний вираз формату українського номера (`+380...`, `0...`, з дефісами/дужками).

2. **Клас Main (налаштування магазину та оформлення замовлення):**
   - `MAX_PRODUCTS = 20` — максимальна місткість каталогу.
   - `DISCOUNT_HIGH_THRESHOLD = 5000.0` (поріг 10% знижки)
   - `DISCOUNT_LOW_THRESHOLD = 2500.0` (поріг 5% знижки)
   - `DISCOUNT_HIGH_RATE = 0.10`
   - `DISCOUNT_LOW_RATE = 0.05`
   - `FREE_DELIVERY_THRESHOLD = 1500.0` (поріг безкоштовної доставки)
   - `STANDARD_DELIVERY_FEE = 150.0` (вартість стандартної доставки)
   - `EXPRESS_DELIVERY_EXTRA = 100.0` (доплата за експрес-доставку)

## Структура проєкту

```text
java-2026/
├── src/
│   ├── Customer.java                 # Клас клієнта з валідацією номера телефону
│   ├── Product.java                  # Клас товару (перевірка цін/кількості, списання зі складу)
│   ├── Main.java                     # Меню (switch-case), обробка винятків, константи, розрахунки
│   └── exception/                    # Пакет для власних винятків
│       ├── ShopException.java               # Базовий checked-виняток магазину
│       ├── InvalidPriceException.java       # Виняток для некоректної ціни товару
│       ├── InvalidQuantityException.java    # Виняток для некоректної кількості товару
│       ├── InvalidPhoneException.java       # Виняток для некоректного номера телефону
│       └── InsufficientStockException.java  # Виняток для недостатньої кількості на складі
├── .gitignore                        # Ігнорування службових файлів (out/, *.class тощо)
├── README.md                         # Документація лабораторної роботи
└── run.bat                           # Скрипт компіляції та запуску
```

## Інструкція запуску

### Швидкий запуск через run.bat (Windows):
Двічі клацніть файл run.bat або запустіть у терміналі:
```cmd
run.bat
```

### Вручну через термінал:
```powershell
chcp 65001 > nul
javac -encoding UTF-8 -sourcepath src -d out src\Main.java
java -cp out -Dfile.encoding=UTF-8 Main
```
